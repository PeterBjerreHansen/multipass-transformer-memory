# Optional unfrozen scaling extensions

This directory intentionally has no runnable manifest yet. It is the home for
post-core arms such as a no-memory adapter, projected-residual recurrence,
strided Memory Attention, dense-plus-strided Memory Attention, or an external
published-method comparison.

Do not add an extension to `unfrozen_scaling_core`. Declare a separate study,
qualification evidence, budget, and comparison contract here after the three
core trajectories are healthy. This keeps optional mechanism work from delaying
the principal scaling result.
