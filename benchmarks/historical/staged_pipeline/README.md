# Superseded staged pipeline

This archive contains the former Stage 0–6 protocol and its original pipeline
document. Stage-5's eight 100M-token arms were completed; Stage-6 contains the
later long-continuation protocol and any locally retained partial artifacts.

The configs and documentation intentionally retain their original
`benchmarks/development/` and `benchmarks/core/` paths. They are provenance,
not active commands. The data recipes referenced by those archived configs were
removed from `data/dolmino/`; only `wiring_2048` and `gpu_2048` remain active.
See `../../README.md` for the current contract.
